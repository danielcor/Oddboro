- [staff] **Decision (2026-11-15): an imported agent's MCP servers become access asks at hire. When the owner hires from a Claude Code agent file, each server it names with an https address, or by the name of a tool the office already has, becomes a read-level access ask on the Desk as the Odd is hired. A server the file runs as a local command, by a plain http address or by an unknown name is listed in the hire window and never run or asked for. The same holds when the owner saves a changed file's instructions on an Odd it already has, less any tool the Odd already holds or has asked for.** The owner sees the asks before pressing Hire and approves or denies each one, so nothing in a file connects or grants anything on its own (the owner's call, 2026-11-15). The sort is `sortServers` in `apps/office/src/lib/staff/claude-agent.ts`; the asks are raised in `apps/office/src/lib/server/imported-servers.ts`.
