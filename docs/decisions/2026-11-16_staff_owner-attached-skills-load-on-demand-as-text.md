- [staff] **Decision (2026-11-16): the owner can attach several SKILL.md files to a local Odd; its prompt carries only each skill's name and when to use it, and the Odd reads one in full with the office's `read_skill` tool.** This keeps every run's prompt short however many skills an Odd has, and works the same on Claude Code, Codex, Gemini and Grok, since all of them reach the office's own tool server. A skill is text only: it grants no tool, folder or permission, and a skill that asks for tools (`allowed-tools`) is told so on the attach form, since Odds get tools only from their Settings tab. Files a skill points at, such as scripts or references, do not come with it. Each tool's own skill loader stays off, as the 2026-10-29 ruling on headless Claude Code says. The name and when to use it come from the file's front matter or from the owner, never from an AI run. Saved in the ledger's `staff_skills` table; a change applies only against the copy the owner reviewed and is recorded as theirs. Detail in `apps/office/CLAUDE.md` and `packages/ledger/CLAUDE.md`.
